# 出海日志 · BRAND QUEST

基于 Phaser 3.88.2 的中文俯视像素调查 RPG。雅加达街区、蜜雪门店、卡拉旺园区和服务车间均可步行探索。游戏以 640×360 逻辑尺寸铺满可用的 16:9 画幅。

**课堂开场**　直接打开 [单文件发行版](dist/brand-quest.html)。用 F 给门头留影，E 进店，走到柜台前接单。把柠檬拖进杯中，按住注茶，茶面进入绿色刻度后松开，把成品拖到托盘。也可用左方向键、空格和右方向键操作。Tab 查看照片、事实来源及模拟任务记录。

**自由探索**　在右上角打开模式菜单。与马路南侧的骑手交谈可开启找取餐夹支线。在候车处按 E 或用 M 乘车前往卡拉旺。万老师是园区中的虚构现场影像记录者。进入车间西侧派工台领取 K-07，在 A1、B2 拣齐指定箱号，再走到东侧协调员身旁交接，完成两站任务后按 J 结案。
