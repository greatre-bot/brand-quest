# 验收标准 / 反粗糙原型检查表

## A. 程序工程
- [ ] `npm install` 成功，`npm run check`、`npm run build` 通过。
- [ ] `npm run dev` 可以打开主菜单；课堂模式、自由模式均可启动。
- [ ] WASD/方向键八方向行走、Shift跑动、角色不穿建筑/柜台/机械/大型道具。
- [ ] 角色与NPC有四方向动画；闲置NPC有合理行为；能够跳过对话。
- [ ] E可与3种以上类型物件互动；F能拍摄证据；Tab手册能看到证据；M能切换不同地区；Esc能关闭面板。
- [ ] 雅加达街区→店内→街区；雅加达→卡拉旺；卡拉旺→车间→卡拉旺，且没有传送卡死。
- [ ] 两个小游戏不是点一下继续，而是有明确输入、动作、反馈、成功/失败/重试；任务有状态持久化。
- [ ] 游戏完成后有多维度结论，不把虚构分数当市场事实。
- [ ] 可脱网运行发行版本，在课堂设备上稳定，不依赖加载第三方图片/脚本。

## B. 场景与艺术
- [ ] 每张户外地图至少4处可辨识可探索兴趣点；不是一本道。
- [ ] 统一角色比例、透视、tile尺寸与建筑比例，无明显AI像素错位/不自然拼接。
- [ ] 真实照片→像素原创资产的映射在 `docs/ASSET_AUDIT.md` 可追溯。
- [ ] 印尼本地街景有文化和生活细节；三一Karawang工业园有有辨识度的厂房/设备参考。
- [ ] 各场景至少3个可选互动，NPC有不同时间/任务状态台词。
- [ ] 碰撞区域、前后遮挡、交互距离等正常。

## C. 内容真实性
- [ ] 每条品牌事实能追溯 `facts`、`source-index`。
- [ ] 明确区分真实背景、研究性推断、模拟故事。
- [ ] 不把公开资料中缺失的NPS、响应时效、设备开机率写成真实事实。
- [ ] 不把实际相距较远的雅加达和Karawang拼成同一路段。
- [ ] 用户视频人物作为参考角色需注意授权与事实身份，不暴露私人视频。
- [ ] 资源来源、作者、版权/使用范围经过核对，未经许可的媒体素材不进入发行包。

## D. 课堂演示
- [ ] 从主菜单到结算（展示模式）实测 ≤ 5分钟。
- [ ] 不需要讲解员一直盯着调试；重要任务有明显提示，关键路径可快速到达。
- [ ] 完整探索10—15分钟有支线和额外细节，非纯文本累积。
- [ ] 如果演示失败，可立即切换录像；备份视频和静态截图可靠。
- [ ] 不制造品牌宣传事件，不恶搞灾难救援，将工业服务任务定位为课堂模拟。
