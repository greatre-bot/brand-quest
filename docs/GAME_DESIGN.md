# 游戏设计总纲 (GDD) — 《出海日志：BRAND QUEST》

## 定位
俯视角像素RPG；中国品牌出海研究 × 印尼真实地点参考重构 × 角色互动 × 轻量操作小游戏。不是填空问答，也不是只靠读文字的互动PPT。玩家是独立调查员，调查为什么在同一海外市场，不同购买方式需要不同的信任证明。

## 开发约束
- 课堂展示4—5分钟；自由探索10—15分钟；必须共享完整地图和存档。
- 640×360逻辑像素，横屏16:9，32px地图网格，人物32×40左右，视角为Stardew-inspired但所有贴图须原创。
- 两个有真实参考的现实地区——雅加达门店街区与Karawang SANY工业园。只能说“基于真实地点的游戏化重构”；两地区用交通转场。
- 同一个场景可以有主线与自由探索，多处可触发但非强制的环境细节。

## 操作设计
- WASD/箭头：八方向；Shift奔跑；E交互；F取景拍照；Tab调查手册；M区域地图；Esc关闭；J结案。
- 玩家不能穿越房屋、树木、柜台和机器；前景遮挡与交互提示必须协调。
- 摄像机平滑跟随；对话不会强迫一口气读大段文字。

## 玩家体验循环
1. 观察：街区与工业园视觉上真实不同。
2. 行动：问人、操作设备/柜台、使用调查相机。
3. 证据：将照片、语录、服务/体验指标存入手册；每条区分来源与模拟信息。
4. 判断：事件有取舍，不是题库“选对拿分”；不同选择让玩家看到代价与风险。
5. 输出：最终比较“消费品牌熟悉感+体验”与“工业品牌证据+服务兑现”。

## 角色
- 玩家调查员：无特定个人身份，方便受众代入。
- 雅加达消费者：提醒广告/符号的认知价值，但复购由体验支持。
- 蜜雪店员：引导可操作的订单模拟。不可自称代表品牌官方数据。
- 影像记录者：根据用户提供视频外观重构成虚构NPC；在园区解锁“调查相机”和摄影支线。不得擅自标记真人身份、真实工作职务或说本人曾在该园区工作。
- 三一服务工程师：介绍可见服务证据，触发工单小游戏。
- 可选：海外采购经理、当地经销商、工业园门卫、送货骑手等。

## 课堂展示时间线（目标）
- 0:00–0:20：片头/进入街区；
- 0:20–1:45：雅加达店内订单操作 + 消费者线索；
- 1:45–2:00：区域交通；
- 2:00–4:05：产业园设备摄影 + 服务任务；
- 4:05–4:40：品牌判断结案；
- 4:40–5:00：切入小组PPT。

## 可选深度
- 每张户外地图3位以上NPC；有生活节奏、对话变化。
- NPC的条件反应：拍完照片 / 完成服务 / 未完成任务，文字和行为不同。
- 支线：寻找一张遗失的工程照片、采访本地顾客、把订单配送到街边工作者。
- 物件互动：相机取景、走位构图、背包、道具检索、基础路线规划。
- 记忆点：发现照片墙/客户影像展示装置，把游戏里收集的图片拼成“品牌证据墙”。

## 学术边界
事实背景以小组M1—M4核验为准。玩家遭遇、服务故障、订单、NPC身份及结果数值全部是课堂模拟。游戏反馈用于解释理论，不能当作市场研究结论。不要对某真实工厂的安保、内部路线提供精确地图。
