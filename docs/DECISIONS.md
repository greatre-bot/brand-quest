# 已决定 / 暂不决定

## 已确定
- 俯视角原创像素游戏，风格灵感来自《星露谷物语》的地图与交互节奏，但不能复制其受版权保护的素材。
- 同一印尼背景；雅加达蜜雪街区与Karawang SANY产业园通过交通转场分隔。
- 真实外观参考用于原创像素地图重构，非现实精确地图或品牌正式仿真。
- 组长兼游戏主程，其他M1—M4组员提供学术输入。
- 有一个借用户视频外观启发的“现场影像记录者”虚构NPC，接入调查相机系统。
- 两套模式：展示4—5分钟、自由探索10—15分钟。

## 待研究后确定
- 门面及柜台主参照已选定 2023 年 Kota Tua 同店内外景（M003、M004）。街区道路和邻铺按游戏动线重排。
- 卡拉旺厂区可公开展示的场景范围与图片权利。
- 用户指定虚构角色称呼为万老师。公开使用可识别真人肖像的权利仍待确认。
- 最终版品牌Big Idea、口号和采购角色定位：需要M2与修订M3共同确认。
- 品牌数据、项目故事与证据照片：等待自主资料研究与版权审核。
- 最终配乐：全部原创或明确许可，暂不使用蜜雪官方主题曲音频。
